# Battleship

Сетевая игра «Морской бой» для двух игроков на Java. Клиент с графическим интерфейсом на Swing подключается к серверу по TCP, игроки расставляют корабли на поле 10×10 и по очереди стреляют друг по другу.

## О проекте

Проект реализует классический «Морской бой» по сети в архитектуре клиент-сервер:

- **сервер** принимает подключения, объединяет игроков в игровые комнаты, хранит расстановку кораблей, обрабатывает выстрелы и определяет победителя;
- **клиент** показывает игроку два поля (своё и противника), позволяет расставить корабли и сделать выстрел кликом мышью;
- обмен данными идёт через сокеты, а сообщения передаются как сериализованные Java-объекты (`ObjectOutputStream` / `ObjectInputStream`).

## Возможности

- Игра двух людей по сети: один создаёт игру, другой присоединяется.
- Ручная расстановка кораблей мышью, поворот корабля, очистка поля и автоматическая расстановка.
- Проверка расстановки: корабли не выходят за границы поля и не касаются друг друга, в том числе по диагонали.
- Пошаговая игра: игрок видит, чей сейчас ход, и получает уведомление о результате каждого выстрела.
- Определение победителя: игра заканчивается, когда у одного из игроков поражены все палубы.
- Несколько игровых комнат на одном сервере: каждая пара игроков играет независимо.

## Правила игры

- Поле: 10×10 клеток.
- Флот каждого игрока (10 кораблей):

| Тип корабля | Размер (клеток) | Количество |
|-------------|-----------------|------------|
| Четырёхпалубный | 4 | 1 |
| Трёхпалубный | 3 | 2 |
| Двухпалубный | 2 | 3 |
| Однопалубный | 1 | 4 |

- Корабли ставятся горизонтально или вертикально и не должны соприкасаться друг с другом.
- Игроки стреляют по очереди, выбирая клетку на поле противника.
- Повторный выстрел в уже обстрелянную клетку запрещён.
- Побеждает тот, кто первым поразит все палубы кораблей противника.

Условные обозначения на поле: серый квадрат — корабль (виден только на своём поле), красный круг — попадание, синий крест — промах.

## Структура проекта

Код разделён на четыре пакета:

| Пакет | Класс | Назначение |
|-------|-------|------------|
| `client` | `Client` | Подключение к серверу, приём сообщений, хранение состояния полей на стороне игрока |
| `client` | `StartMenu` | Стартовое меню: «Создать игру» / «Присоединиться» |
| `client` | `ShipPlacement` | Экран расстановки кораблей |
| `client` | `GameUI` | Игровой экран с двумя полями и диалогами с результатами |
| `client` | `GameBoardPanel` | Отрисовка поля и обработка кликов по полю противника |
| `common` | `Message` | Сообщение, которым обмениваются клиент и сервер |
| `common` | `Constants` | Размер поля и набор кораблей |
| `server` | `Server` | Точка входа сервера, приём подключений, подбор комнаты |
| `server` | `GameRoom` | Игровая комната на двух игроков, смена хода |
| `server` | `PlayerHandler` | Обработка сообщений одного игрока, расчёт результата выстрела, проверка конца игры |
| `model` | `Board`, `GameModel` | Модель игрового поля и партии |

## Сетевой протокол

Клиент и сервер обмениваются объектами `Message`. Поле `type` задаёт тип сообщения:

| Тип | Направление | Описание |
|-----|-------------|----------|
| `CREATE_GAME` | клиент → сервер | Создать новую комнату |
| `JOIN_GAME` | клиент → сервер | Присоединиться к свободной комнате (если её нет, создаётся новая) |
| `PLACE_SHIPS` | клиент → сервер | Отправить расстановку кораблей (`ships`) |
| `SHOOT` | клиент → сервер | Выстрел по координатам `x`, `y` |
| `RESULT` | сервер → клиент | Результат выстрела: координаты, `hit`, и `targetIsEnemy` (по кому стреляли с точки зрения получателя) |
| `START` | сервер → клиент | Ваш ход |
| `WAIT` | сервер → клиент | Ход противника |
| `GAME_OVER` | сервер → клиент | Игра окончена, `hit = true` у победителя |

Сервер слушает порт **5000**.

## Запуск

### Требования

- JDK 17 или новее
- Maven 3.6+ (если собираете через Maven)

### Получение кода

```bash
git clone https://github.com/Suzumixara/Battleship.git
cd Battleship
```

### Сборка

```bash
mvn clean compile
```

Проект также можно открыть в IntelliJ IDEA (в репозитории есть файлы проекта `.idea` и `.iml`).

### Запуск сервера

Запустите класс `server.Server`. В консоли появится сообщение «Сервер запущен на порту 5000».

```bash
java -cp target/classes server.Server
```

### Запуск клиентов

Для игры нужны два клиента. Запустите класс `client.Client` дважды (в двух терминалах или двух конфигурациях запуска в IDE):

```bash
java -cp target/classes client.Client
```

По умолчанию клиент подключается к `localhost:5000`. Чтобы играть по сети, замените адрес в методе `main` класса `Client` на адрес компьютера, где запущен сервер.

## Как играть

1. Запустите сервер и двух клиентов.
2. Первый игрок нажимает **«Создать игру»**, второй — **«Присоединиться»**.
3. Расставьте корабли:
   - левая кнопка мыши ставит текущий корабль (начиная с самого большого);
   - правая кнопка мыши или кнопка **«Повернуть»** меняет ориентацию;
   - **«Авто»** расставляет корабли случайно, **«Очистить»** сбрасывает расстановку;
   - **«Подтвердить»** отправляет расстановку на сервер.
4. Когда оба игрока подключились, игра начинается: первым ходит создатель комнаты.
5. На своём ходу кликните по клетке на поле противника. Результат выстрела появится у обоих игроков.
6. Игра заканчивается, когда все корабли одного из игроков поражены.

## Ограничения и планы развития

- Сообщение о потоплении корабля («убил») пока не реализовано: игроки видят только «попал» и «промахнулся».
- Ход переходит к сопернику после каждого выстрела, независимо от попадания.
- Адрес сервера в клиенте задан в коде.
- Обрыв соединения одним из игроков не обрабатывается.
- Классы `Board` и `GameModel` (пакет `model`) описывают игровую логику, но сетевой сервер сейчас считает результат выстрела самостоятельно в `PlayerHandler`.
